# 一加 7 Pro ColorOS 17 移植版 更新说明

**版本：ColorOS17.0.1.201(los20261011-r2)**
关于本机显示：ColorOS 17.0.1 / GM1910_17.0.1.201(los20261011-r2)
适用机型：一加 7 Pro（GM1910，guacamole，骁龙 855）
底包：一加 16（PYB110）ColorOS 17.0.1.201 + LineageOS 24（20261011）vendor 与内核

## 一、本版重点

1. **完整刷机包**：所有分区（固件、dtbo、vbmeta、boot、vendor、system）和 my_stock 都在一个包里，不需要先刷底包。
2. **一个包两种刷法**：免 Root（NoRoot）和 Magisk v31.0（Root）。
3. **系统底包升级**：从一加 15（PLK110）17.0.0.105 换成一加 16（PYB110）17.0.1.201。
4. **相机换成一加 16 原生相机 7.012.185**（专门为 7 Pro 移植修改）。
5. **2026-11-20 更新（同名重新发布，替换之前的 r2 包）**：修复微信视频通话对方画面被拉伸；加回 7 Pro 原厂（H.40）一加相机。已经刷过之前 r2 的手机，用「情况 A：升级」再刷一次即可，数据保留。

## 二、相机

可以正常使用：

- 拍照：主摄、0.6× 超广角、2×、3× 长焦、前置
- 人像模式拍照（没有背景虚化）
- 视频 1080p
- 滤镜（预览和成片都有效果）
- 实况照片（Live Photo）
- 慢动作 1080p 240 帧
- 延时摄影（固定倍速，和 7 Pro 原厂相机的做法一样）

已移除（7 Pro 硬件做不到，入口已去掉，避免点进去闪退或卡死）：

- 双景录像（需要前后摄同时工作，7 Pro 不支持）
- 长曝光（光绘，需要 ColorOS 原生影像引擎）
- 人像美颜（需要新机型的人脸数据，7 Pro 的相机驱动不提供）
- 视频/人像背景虚化（需要 NPU，855 没有）

**新增：7 Pro 原厂一加相机（H.40，7.2.47）**，和 ColorOS 相机同时存在（桌面上两个相机图标）。原厂相机的拍照、录像、切换镜头都可以用，录像用的是以前版本里修好的版本。之前在 PYB 底包上它的后台服务一启动就闪退，这次已修复。

## 三、其他修复和改动

- **微信视频通话对方画面被拉伸**的问题已修复（对方画面中途改变比例时，例如从 20:9 变成 4:3，以前会被拉伸铺满屏幕）。
- 去掉无线充电相关入口（7 Pro 没有无线充电线圈）：充电设置里的「无线充电」「反向无线充电」和控制中心的反向充电开关。
- 省电模式下屏下指纹不亮、无法解锁的问题已修复。
- 以前版本的各项修复（通话、音频、传感器、显示、充电、定位等）都保留。

## 四、刷机要求

- 已解锁 BL 的一加 7 Pro（fastboot 显示 msmnile）。
- 电脑装好 adb / fastboot（platform-tools）。
- 电脑剩余空间约 13 GB，手机存储剩余约 8 GB。
- **不需要先刷任何底包**，包内已带ColorOS 12 H.40 固件，脚本会自动刷入。刷固件需要 BL 允许刷关键分区；如果脚本提示固件被跳过（critical partition … skipped），手机会保留原来的固件：原来就是 H.40（或从 H.40 刷过 LineageOS）没有问题，否则请先执行 `fastboot flashing unlock_critical`，再重新运行一次脚本。

## 五、刷机脚本用哪个

解压后的文件夹里有这几个脚本，**只需要运行其中一个**：

| 你的电脑      | 不要 Root                             | 要 Root（Magisk）                     |
| ------------- | ------------------------------------- | ------------------------------------- |
| Windows       | 双击 **`Install-NoRoot.bat`** | 双击 **`Install-Magisk.bat`** |
| Linux / macOS | `bash ./install.sh`                 | `bash ./install.sh --magisk`        |

- `install.ps1` 是 Windows 脚本的主体，由两个 .bat 调用，不用单独运行。
- 不确定要不要 Root，选 `Install-NoRoot.bat`。以后想要 Root，再运行一次 `Install-Magisk.bat` 即可（保留数据）。
- 想先检查一遍：Windows 在命令行运行 `Install-NoRoot.bat -DryRun`，Linux/macOS 运行 `bash ./install.sh --dry-run`。

## 六、安装步骤

**准备**

1. 电脑安装 platform-tools（adb、fastboot），并加入 PATH（命令行输入 `adb version` 能显示版本即可）。
2. 下载 `OnePlus7Pro-ColorOS17.0.1.201(los20261011-r2).zip`，用 `RELEASE-SHA256SUMS.txt` 核对 SHA-256。
3. **把压缩包完整解压**（不要在压缩包里直接双击脚本），得到 `ColorOS17.0.1.201(los20261011-r2)` 文件夹。
4. 用数据线连接手机，电脑上只连这一台手机。

**情况 A：升级（以前刷过本网盘内Rom，可保留全部数据）**

1. 手机正常开机，开发者选项里打开 USB 调试，电脑弹出的授权点「允许」。
2. 运行上面选好的脚本。脚本会：校验镜像 → 把 my_stock 拷到手机 → 自动重启到 fastboot → 刷入当前槽位 → 询问是否清除数据。
3. 问「Type WIPE to wipe」时**直接回车**（不清除数据）。
4. 手机自动重启进入新系统，脚本显示 `Done` 即完成。整个过程约 10 分钟，大部分时间在拷贝 my_stock（约 6.6 GB）。

**情况 B：全新安装 / 从氧OS、LineageOS 或其他系统刷入（会清空手机）**

1. 先备份手机里的照片、资料，这个过程会清空全部数据。
2. 手机关机后按住「音量减 + 电源」进入 fastboot 模式（或开机打开 USB 调试也可以）。
3. 运行上面选好的脚本。
4. 问「Type WIPE to wipe」时输入大写的 **`WIPE`** 再回车（从其他系统刷入必须清除）。
5. 手机重启后第一次开机，脚本会等待手机出现，然后自动把 my_stock 写进手机再重启一次。**第一次开机看起来像卡在开机画面是正常的**，不要拔线，等脚本显示 `Done`。

**说明**

- 脚本只刷当前槽位，另一个槽位保持原样，出问题可以切回去。
- 刷入前会校验每个镜像的 SHA-256，有任何损坏会直接停止。
- 固件分区如果被 BL 拒绝（提示 critical partition … skipped），手机已经是 H.40 固件时属于正常现象；否则请执行 `fastboot flashing unlock_critical` 后重新运行脚本。
- Magisk 版：脚本会自动安装 Magisk App，打开一次完成初始化即可。

## 七、已知问题

- 这是开发版：SELinux 为宽容模式，adb 默认 root。对安全有要求的场景不建议使用。
- 刷入后的头一两天，部分应用第一次打开可能稍慢：系统会在空闲充电时在后台重新优化应用，之后恢复正常。
